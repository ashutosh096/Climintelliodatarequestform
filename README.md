# ClimIntellio Dataset Request Form

An interactive and responsive web form designed for **ClimIntellio** dataset access requests, built for high conversion, professional aesthetic, and instant submission logging directly into Google Sheets.

## ✨ Features
- **Dynamic Multi-select Climate Hazards & Metrics**: Interactive badge pills and categorized dropdowns.
- **Form Validation & Modals**: Intuitive error highlighting and personalized confirmation modals.
- **Direct Google Sheets Integration**: Submissions are automatically recorded via Google Apps Script without requiring a backend database.
- **Auto-Formatting & Wrapping**: Google Apps Script automatically wraps text and formats selected hazards and metrics into clean bullet points.
- **Ready for Vercel / Static Hosting**: Self-contained with `index.html` for 1-click deployment.

## 🚀 Deployment
Deployable directly on [Vercel](https://vercel.com):
1. Import this repository in Vercel.
2. Framework Preset: **Other**
3. Deploy!
